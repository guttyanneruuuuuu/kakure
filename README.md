# 🦎 めっちゃカメレオン（ブラウザ版）

スマホの**横画面**で遊べる、かくれんぼ 3D ブラウザゲーム。
PC版「めっちゃカメレオン」のコアメカニクス（擬態ペイント・ポーズ・カラーコピー）を
タッチ操作向けに再設計しました。GitHub Pages などの**静的ホスティングだけ**で動きます。

## 🎮 あそびかた

| 操作 | やり方 |
|------|--------|
| 移動 | 画面**左側**をドラッグ → バーチャルジョイスティック |
| カメラ | 画面**右側**をスワイプ |
| 🎨 ペイント | カラーパレットを開いて体の色を変える |
| 💧 スポイト | ボタンを押してから物をタップして色をコピー |
| 🧍 ポーズ | ボタンを**長押し**でじっと隠れる（擬態UP） |

近くの物と**同じ色**に塗って、ポーズして隠れると擬態メーターが上がります。
👹 オニに見つからないように 90 秒間逃げ切ろう！

## 🛠 技術スタック

- **Three.js**（CDN / import map 経由）— ビルド不要、静的配信でそのまま動作
- Vanilla JS（ES Modules）+ HTML + CSS
- バックエンド不要のシングルプレイ MVP

## ▶️ ローカルで動かす

ES Modules を使うので `file://` ではなくサーバー経由で開いてください。

```bash
python3 -m http.server 8080
# → http://localhost:8080 をスマホ横画面 or PC で開く
```

## 🚀 GitHub Pages デプロイ

このリポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch**
で `main` ブランチ / `/ (root)` を選ぶだけで公開できます（ビルド工程なし）。

## 📁 構成

```
index.html        画面・UI・import map
style.css         レイアウト（横画面UI / ジョイスティック / パレット）
src/
  main.js         ゲームループ・カメラ・擬態判定・オニAI・HUD
  controls.js     タッチ操作（左ジョイ / 右スワイプ / キーボード）
  world.js        ステージ・色付きオブジェクト・オニ生成・衝突
  player.js       カメレオンキャラ・ペイント・ポーズ
```
